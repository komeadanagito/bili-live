# 初版功能文档

## 产品目标与技术选型

将登录、直播控制和实时互动消息整合成桌面应用。前端 React + TypeScript，桌面容器 Tauri 2，后端 Rust。初版以 Windows 为主要验证平台。音视频推流由 OBS 等外部软件完成。

## 已实现功能

### 账号与登录

- 获取二维码，前端显示 PNG，手机扫码确认。
- 每 2 秒轮询登录状态，区分等待扫码、待确认、过期和成功；关闭弹窗停止前端轮询。
- 二维码过期/网络错误可手动刷新。
- 后端保存 Cookie 到系统凭据管理器；前端不接收 Cookie。
- 启动查询登录账号、UID、头像、账号直播间和直播状态。
- 退出登录删除系统保存的凭据，断开弹幕连接。
- 本应用开启直播期间禁止切换和退出账号，防止失去停播凭据。

### 直播控制

- 获取直播分区树并选择子分区。
- 查询最近分区。
- 当前登录账号开播，返回 RTMP 地址、串流密钥及场次标识。
- 默认隐藏凭据，用户主动显示或复制。
- 停播前弹窗确认，后端调用停播接口后查询场次统计。
- 停播成功与统计可用性分别处理：统计接口失败不视为停播失败，不显示虚假的零统计。
- 关闭应用不自动下播；需用户明确停播。

### 实时互动

- 输入单个直播间数字 ID，支持短号解析。
- 网页端 WBI 签名、设备标识、服务器列表、连接认证和心跳。
- 弹幕认证成功后才显示“已连接”；游客接入提示用户信息可能打码。
- 断线采用递增间隔重连（2 秒起、最多 30 秒），重新获取认证并轮换服务器。
- 手动断开、切换房间和退出账号时取消旧连接。
- 接收普通/跨房弹幕、礼物、上舰、SC、SC 删除通知、进房/关注/分享等互动。
- 支持新版礼物及互动 Protobuf 消息。
- 补充部分网页端点赞、累计观看、开播和停播通知。
- 未知事件忽略，不将未解析事件错误展示成完整业务功能。
- SC 删除目前提供通知，并不自动删除历史中相应留言。

### 展示与统计

- 深色桌面控制台、账号区、直播控制、推流配置、房间连接、互动消息与下播统计。
- 按类型筛选、用户或文本搜索、清空本地消息。
- 内存最多保留最近 500 条，无历史数据库。
- 官方场次统计包括时长、观看、最大在线、弹幕数、粉丝和粉丝勋章变化、金仓鼠流水。
- 金仓鼠流水按原值展示，不自行换算为人民币收入。
- 支持 `npm run tauri web` 启动 Web 调试版，通过本地 Rust 后端提供完整的 HTTP 与 WebSocket 链路，扫码登录、开播、串流配置、实时弹幕接收等功能与 App 完全一致。

## 暂不包含

- B 站开放平台模式（需要项目及密钥申请，后续接入）。
- 多直播间同时监听。
- 画面/摄像头/声音采集、编码和实际推流。
- OBS 浏览器源、语音播报、自动回复、互动玩法。
- 持久化历史、排行榜、封禁管理和自动更新。
- macOS/Linux 安装包验收。

## 验收建议

1. `npm run build` 与 Rust 编译检查通过。
2. 单元测试通过，包括协议压缩、多包和 Protobuf。
3. `npm run tauri dev` 能打开桌面窗口并正确显示无账号状态。
4. 用户实际扫码，确认账号与房间信息正确，重启后登录可恢复。
5. 选择分区开播，复制到 OBS 并从 OBS 验证实际推流。
6. 连接有效房间，核对弹幕、礼物、SC 等实际消息；断网后验证重连，手动断开后确认不再重连。
7. 停播确认后核对 B 站状态与统计；统计失败时确认提示不可用。
8. 退出登录，确认系统凭据移除；浏览器预览确认桌面操作禁用。

涉及扫码、开播、停播的验收会真实改变账号状态，必须由账号所有者在确认后执行；代码编译和单元测试不替代这些线上验收。
